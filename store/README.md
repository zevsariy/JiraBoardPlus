Язык карточки — русский. Категорию выберите из актуального списка кабинета: рабочие инструменты / производительность. Не указывайте поддержку Jira Cloud.

Скриншоты получены из текущего кода расширения с вымышленными данными и перехватом всех сетевых запросов. Это демонстрация интерфейса, а не реальные данные клиента. Сцены роадмэпа сняты в тестовом браузере, интерфейс Jira вокруг них не имитируется. Промоизображения используют существующий логотип проекта, без сторонних брендов.

## Перед отправкой на ревью

1. Загрузите ZIP расширения из указанного релиза и проверьте версию в кабинете.
2. Вставьте описания и публичные ссылки; загрузите изображения.
3. Заполните Privacy practices по текущему коду и политике. Не выбирайте «данные не обрабатываются»: используются данные Jira и необязательный API-ключ ИИ.
4. При необходимости предоставьте ревьюеру временную тестовую Jira через закрытые поля кабинета. Пароли не должны попадать в GitHub, описание или скриншоты.
5. Проверьте карточку в предпросмотре и отправьте на ревью из своего аккаунта издателя.

Старый соседний каталог `chrome-web-store-kit` содержит исторические материалы 0.9/0.10; актуальный источник — этот каталог в Git. Политика хранится в единственном актуальном файле [PRIVACY.md](../PRIVACY.md), чтобы её копии не расходились.

## Воспроизведение изображений

Нужны Node.js, Playwright и установленный Microsoft Edge. Выполнять из корня репозитория:

```sh
node store/generate.cjs
node store/capture-roadmap.cjs
```

Первый скрипт формирует демонстрацию отчёта и промо. Второй запускает существующую проверку роадмэпа и дополнительно снимает его интерфейс в 1280×800. Ответы Jira подставные, настоящая Jira не используется. Скрипты и маркетинговые материалы не входят в runtime ZIP расширения.
