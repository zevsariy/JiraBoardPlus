# Проверка Refinement · 0.7.7

1. Обновите расширение и страницу инструментов. В шапке видна версия 0.7.7. В общих настройках должны быть указаны URL Jira и ключ проекта. При открытии страницы автоматически появляется количество досок проекта; никаких кнопок первоначальной загрузки досок нет.
2. В поле «Доска проекта» введите часть имени с другим регистром. Выберите Scrum-доску кликом или Enter. Ожидается готовый список совпадений; вручную вводить ID нельзя и не нужно. Настройки и спринты этой доски загружаются автоматически.
3. Выберите «Бэклог без спринтов» и оценки «Из настроек доски». Включите нужные проверки, нажмите «Проверить». В сводке видно название доски, выборка бэклога и фактическая единица оценки. Задачи активных/будущих спринтов не должны входить. Историческое участие в закрытом спринте само по себе не исключает задачу из текущего бэклога.
4. Переключите выборку на «Конкретный спринт». Появляется поле с поиском по названиям; доступны будущие, активные и завершённые спринты с пометкой состояния. Выберите будущий спринт и нажмите «Проверить». В сводке указано его название; выдача содержит задачи именно этого спринта в пределах доски. Поля проверяются в текущем состоянии.
5. Выберите Kanban-доску. В выборе источника нет спринтов, есть «Бэклог Kanban» и «Первая колонка Kanban». Выберите бэклог и проверьте. Он должен совпадать с отдельным бэклогом Jira. Если Jira не предоставляет бэклог этой доски, ожидается ошибка, а не незаметная подстановка всей доски.
6. Выберите «Первая колонка Kanban». Видно имя колонки, например Selected for Development; сравните с UI вашей доски. При иной конфигурации уточните колонку в списке. Нажмите «Проверить»: должны войти задачи всех статусов, привязанных к выбранной колонке, в пределах фильтра доски. Задачи соседних колонок не должны входить.
7. Если у Kanban нет поля оценки, в режиме «Из настроек доски» ожидается объяснение. Выберите SP или Original Time Estimate и повторите; либо отключите правило проверки оценки. Остальные проверки должны работать. Для доски с оценкой во времени авто-режим должен показывать Original Time Estimate (h), а не SP.
8. Во время проверки поменяйте доску или выборку. Старый результат очищается; завершившийся позже запрос не должен появиться под новой выбранной доской. При ошибке нажмите крестик — сообщение скрывается. Ошибки загрузки списков имеют кнопку повторения.
9. На всей странице инструментов нет полей Context path. Ссылки задач используют базовый URL из настроек, включая /jira, если он действительно настроен на сервере. Во вкладке «История переносов» доска также выбирается по имени из готового списка Scrum-досок проекта.
10. Режим «Свой JQL», сохранение правил и импорт/экспорт профиля продолжают работать. Если анализируется JQL с автооценками, выберите доску как источник поля оценки; сам JQL не дополняется фильтром доски.
