# Проверка полей родителей 0.18.0

1. Настройки → «Поля родителей на карточках»: включите активную доску и бэклог. Также включите общий визуал и анализ бэклога. Оставьте типы Task, Story и связи Epic Link, Parent Link либо задайте реальные названия/ID своих полей.
2. В «Поля из Epic» укажите Risk и Status comment (если эти поля существуют). В «Поля из Component» укажите Due Date и Status. Сохраните. Для неоднозначного названия используйте точный ID поля.
3. Откройте доску. Наведите на «↥ Родители» у Task/Story: увидите ключ Epic, его поля, затем ключ Component и его поля. Значения должны совпадать с Jira. Клик и фокус Tab тоже открывают окно; Escape закрывает.
4. Откройте Details нескольких карточек: метки не должны исчезать и загружаться заново. Проверьте тот же сценарий в бэклоге.
5. Проверьте пустое поле, отсутствующего родителя и родителя без доступа. Ожидаются отдельные сообщения, а не выдуманные значения. Bug без включения в список типов не получает метку.
6. Отключите галочку для активной доски: метки исчезают там, в бэклоге остаются. Отключите общий визуал: меток нет нигде.
7. Измените поле родителя в Jira, дождитесь обновления (до двух минут плюс цикл проверки) или нажмите «Обновить» в сводке Board Plus, если она включена. Значение должно обновиться.
