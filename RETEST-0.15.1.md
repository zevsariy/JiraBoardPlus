# 0.15.1 — Стиль встроенных элементов Jira

После обновления расширения перезагрузите вкладки Jira.

- На активной доске и в бэклоге проверьте метки daily, блокировок, билда, времени и «После старта». Ожидаются компактные прямоугольные метки со скруглением 3 px. Настроенные вами цвета рамок/заливки карточек сохранены.
- Откройте подсказку времени и «После старта»: фон, текст, таблица и плотность должны сочетаться с Jira.
- Откройте личные заметки из карточки, Details и полной страницы issue: нейтральная кнопка, модальное окно с синим основным действием; CRUD работает как раньше.
- В родном Sprint Report проверьте дополнения, снимки, фильтры и экспорт: кнопки стандартной плотности AUI (32 px), синий основной акцент, скругления 3 px.
- Включите ИИ для доски: кнопка открытия и окно анализа используют тот же Jira-профиль. Запрос выполняется только по подтверждению отправки в окне.
- Поле Team сохраняет прежний компактный вид и редактирование.
- При тёмной теме ОС и светлой Jira встроенные панели остаются светлыми. Если Jira предоставляет переменные AUI/DS, дополнения наследуют их; автоматического определения произвольного стороннего CSS нет.
- Собственные вкладки, popup, метрики и роадмэп расширения сохраняют оформление версии 0.15.0 и системную тему.

Проверено на синтетических AUI-страницах и API-фикстурах, без запросов к корпоративной Jira. Если ваша Jira имеет нестандартную тему, точное совпадение нужно проверить на ней.
