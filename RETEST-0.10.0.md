# Проверка 0.10.0: ИИ
1. Без настройки модели кнопок нет; все прежние выгрузки работают.
2. Задайте endpoint /v1, имя модели, необязательный ключ; включите две кнопки. Сохраните и обновите Jira.
3. Доска/бэклог: кнопка справа внизу → окно со снимком видимых карточек. До «Отправить» запросов к модели нет.
4. Sprint Report/Метрики: загрузите спринт, задайте фильтр. Кнопка анализа → снимок содержит выбранные задачи и метрики, без описаний, changelog и личных заметок.
5. Отправьте снимок: текст ответа внутри окна, HTML модели не исполняется. Отмените долгий запрос, повторите. Закрытие/Escape отменяет запрос.
6. Ошибочный endpoint/ключ/модель: понятная ошибка, повтор доступен. Незаполненная модель не позволяет включить функцию.
7. Измените промпт; проверьте его на своём тестовом API. Восстановите стандартный.
8. Сохраните настройки без нового ключа — старый остаётся; галочка удаления убирает ключ. Экспорт профиля не содержит ключа.
9. Отключите каждую кнопку, обновите страницу — соответствующей кнопки нет. Общий выключатель визуала скрывает элементы на Jira.
10. Локальная модель: http://localhost:порт/v1 разрешён; произвольный HTTP сервер отклоняется.
