# Ручная проверка 0.12.0

1. Выберите Kanban-доску в «Метрики команды». После загрузки появились четыре графика: недельные столбцы, возраст задач, время в статусах, точки времени прохождения. Переключите Cycle time / Lead time: подпись и точки меняются.
2. По очереди выберите P50, P70, P80, P85. Заголовки таблицы статусов, подписи карточек и линия на точечном графике показывают выбранный P. Новая загрузка Jira не нужна. Медиана отдельно; на чётной выборке P50 может от неё отличаться.
3. Наведите курсор на столбец/точку: видны ключ/период, показатель и точное значение. Нажмите — откроется список соответствующих задач. Проверьте Tab → Enter для клавиатуры.
4. Фильтруйте Bug/Story и подзадачи. Графики и таблицы используют одну выборку. Для пустой выборки или отсутствия истории показывается сообщение, а не придуманная линия.
5. Раскройте «Графики», снимите галочки. Соответствующие графики исчезают. Повторно выберите доску: настройки видимости и перцентиля восстановились.
6. Измените порог возраста: превышающие его полосы красные, линия порога перемещается. Для >30 задач отображается подпись об ограничении top-30.
7. На Scrum-доске загрузите динамику спринтов. Появились графики плана/выполнения/добавлений и повторно незавершённых. Переключите количество/SP/часы: отображаются только подходящие единицы; неизвестные оценки обозначены ?.
8. Выгрузите JSON обзора и откройте окно ИИ: в данных указан выбранный percentile, значения совпадают с графиками. В Sprint Report выберите P80 и проверьте карточку Cycle time и JSON этого отчёта.
9. Уменьшите ширину окна: графики прокручиваются внутри своих блоков, вся страница не расползается по горизонтали.
10. Недельные столбцы с * обозначают неполные недели. Создание не равно попаданию на доску; исторический WIP и cumulative flow не строятся.
