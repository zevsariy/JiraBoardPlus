# Мастер и справка — 0.8.0

1. Новая установка в отдельном профиле браузера открывает «Первоначальная настройка», шаг 1 из 4. При обычном обновлении вкладка сама не открывается; мастер доступен через меню расширения.
2. Оставьте проект пустым и нажмите «Далее»: появится подсказка, перехода не будет. Введите ключ проекта из номера задачи, например DEMO. Не указывайте полное название.
3. Перейдите к статусам, измените ответы, перезагрузите вкладку. Черновик должен восстановиться. Назад возвращает к предыдущему вопросу без потери ответа. Один и тот же рабочий и завершённый статус вызывает ошибку.
4. На шаге функций выберите нужные галочки и единицы времени. На последнем шаге проверьте сводку. До нажатия «Сохранить и начать» рабочие настройки не изменяются. При другом адресе Jira браузер может запросить разрешение, а смена сервера требует подтверждения очистки базы результатов JQL.
5. После сохранения появляется экран завершения со ссылками на метрики, JQL, refinement, настройки и справку. В настройках выбранный проект и параметры совпадают с ответами. Параметры, которых не было в мастере (например цвет/толщина рамки), сохраняют прежние значения. Готовых JQL не появляется.
6. Откройте мастер повторно: он подставляет текущие настройки. Измените проект и выберите «Продолжить позже». Действующий проект не изменяется; повторное открытие восстанавливает черновик.
7. Откройте «Справка» из меню, настроек, метрик, JQL или инструментов. Проверьте переходы по содержанию, описания всех функций, ссылки на страницы. Справка доступна при отключённой сети. На узком экране нет горизонтальной прокрутки.

Автоматически проверено: 48 модульных тестов, мастер в реальном расширении в изолированном профиле Edge, сохранение/черновик/валидация/откладывание, сохранность прочих настроек, offline-ссылки и узкая вёрстка; общий smoke-тест расширения. Корпоративная Jira не вызывалась. Сам мастер не проверяет наличие проекта — проверка доступа происходит при загрузке досок на соответствующих страницах.
