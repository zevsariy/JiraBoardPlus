# Проверка 0.20.1

1. Откройте граф. Масштаб колёсиком должен меняться заметно быстрее (чувствительность увеличена с 0.2 до 1). Кнопки +/− меняют масштаб вокруг центра, максимальный масштаб увеличен до 4.
2. Откройте несколько вкладок расширения. В popup выберите «Тёмная»: все вкладки и popup переключаются без перезагрузки. Повторите со светлой темой, включая ОС в тёмном режиме.
3. Откройте окно анализа ИИ: оно соответствует выбранной теме. Перезапустите popup и страницу — выбор сохраняется.
4. Выберите «Как в системе»: тема снова соответствует ОС. Встроенные дополнения на страницах Jira сохраняют её родное оформление.
5. Переключите тему при открытом графе: позиции карточек и текущий масштаб сохраняются.
