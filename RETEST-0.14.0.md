# Проверка 0.14.0

Обновите расширение на chrome://extensions и перезагрузите вкладку Jira, чтобы применился новый код кнопки заметок.

1. **Без спринта.** Меню → Роадмэп → настройки: включите «Не назначен спринт», выберите Task/Story (Ctrl/Cmd для нескольких), сохраните. Откройте релиз с незавершённой Task без Sprint. Ожидается жёлтая подпись «Не назначен спринт» в дереве и счётчик в сводке, даже при заполненных Target Start/End. Component/Epic не помечаются, если их типы не выбраны. Назначьте любой спринт и обновите — подпись исчезнет. Завершённые задачи и внешние блокеры исключены. Выключите правило, сохраните — метки исчезнут. Для Kanban оставьте правило выключенным. Только закрытый спринт тоже считается назначением: это проверка пустого поля, а не текущей загрузки команды.
2. **Дополнительные поля.** В настройках роадмэпа найдите Assignee, Priority и своё custom field по части имени без учёта регистра. Добавьте кликом/Enter. Кнопками ↑/↓ поменяйте порядок, удалите одно поле. Сохраните: значения должны появиться под названиями задач в заданном порядке. Длинный текст целиком виден при наведении или в подробностях. Пустое поле — «—», недоступное — «Недоступно». После повторного открытия вкладки настройки сохраняются.
3. **Выгрузка.** Выберите JSON и «Выгрузить для ИИ», затем повторите с Markdown. Файл содержит весь загруженный релиз, иерархию, правила, зависимости, предупреждения и выбранные поля; сворачивание/Team-фильтр не обрезают данные. Личных заметок в файле нет. Выбранные описания/комментарии Jira включаются как дополнительные поля.
4. **ИИ.** В общих настройках включите модель и «Кнопка анализа роадмэпа», сохраните. В роадмэпе нажмите «Анализ в ИИ»: видно модальное окно с сервером и снимком, запрос ещё не отправлен. Проверьте поля; нажмите «Отправить и анализировать». Ожидается форматированный ответ. Закрытие или отмена прерывают запрос. Снимок >200 000 символов даёт понятное сообщение; файл по-прежнему можно выгрузить. Отключите галочку — кнопка скрывается.
5. **Личные заметки на активной доске.** Включите личные заметки и визуальные дополнения. Перезагрузите Jira. Нажмите кнопку «Личные заметки» мышью прямо на карточке активного спринта: должно открыться окно заметок этой задачи, без запуска перетаскивания/редактирования Jira. Создайте заметку. Откройте ту же задачу в бэклоге и по прямой ссылке: запись доступна; редактирование и удаление работают сквозным образом. Выключите фичу — кнопки исчезают.

Разработка проверена на локальных синтетических данных без запросов к корпоративной Jira. При ошибке сообщите режим страницы, действие и текст ошибки; секреты API не присылайте.
