Подключение к Jira и проект

Доски выбранного проекта загружаются автоматически. Если Jira установлена по пути /jira, включите его в URL. Chrome запросит доступ к выбранному домену. После сохранения адреса перезагрузите вкладки Jira.

Дополнения на досках

Общие правила статусов

Без учёта регистра, пробелы по краям игнорируются. Общие правила для daily, Cycle time и возвратов из завершённых статусов в Sprint Report и метриках. Сохраните кнопкой «Сохранить настройки». Оценки SP/часы остаются настройкой каждой доски.

Sprint Report

Сводка перед daily

Названия через запятую, без учёта регистра. «РАЗБЛОКИРОВАНА» — только когда все задачи по связи is blocked by имеют один из этих статусов. Общая категория Done здесь не применяется.

Поля родителей на карточках

Метка «Родители» показывает выбранные поля при наведении, фокусе или клике. Общий переключатель визуала должен быть включён. Для бэклога также включите общий анализ бэклога в разделе дополнений на досках. Daily включать не требуется.

Введите названия полей (без учёта регистра) или ID, по одному на строку либо через запятую. Всего до 20. Для одинаковых названий используйте customfield_12345. Поля выводятся в заданном порядке, сначала Epic, затем Component. Пустое значение отличается от недоступного поля. Данные обновляются раз в две минуты; общие родители загружаются один раз за цикл.

Наличие билда

Без учёта регистра. Метка появляется, когда статус совпадает и поле заполнено. При одинаковых названиях полей укажите точный ID, например customfield_12345. Для бэклога включите его анализ в разделе «Дополнения на досках».

Добавленные после старта

Время в статусе

Одни единицы для карточки и popup. Режим применяется и к Jira, и к Timepiece. День = 24 ч, неделя = 168 ч — единицы отображения; рабочий календарь Timepiece выбирается отдельно.

Календарь Timepiece 5.1

Длительность рассчитывает Timepiece по выбранному календарю и режиму визитов.

normalHours — 24×7; 0 — рабочий календарь по умолчанию; число — ID вашего календаря Timepiece. Для совпадения с отчётом выберите тот же календарь.

Сохранение применит настройки к открытым вкладкам. Подключение сохраняется отдельно в своём разделе.

Анализ через ИИ · необязательно

Можно указать базу API или полный путь /chat/completions. Для локальной модели разрешён HTTP на localhost или 127.0.0.1. Используется Chat Completions без streaming.

Ключ хранится локально в профиле Chrome, не включается в экспорт настроек. Данные передаются выбранному серверу только после нажатия кнопки в окне анализа. Условия хранения на стороне сервера определяет его владелец.
