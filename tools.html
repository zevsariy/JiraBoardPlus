Исключения и настройки по типам задач

По умолчанию выбранные выше проверки применяются ко всем типам. Для отдельного типа можно оставить только часть этих проверок или отключить их все. Общая выключенная проверка не запускается ни для одного типа.

История переносов

Повторное участие видно по отчётам выбранной доски. Перенос здесь — незавершённая задача в закрытом спринте, которая затем присутствует в более позднем непересекающемся спринте. Это наблюдение по отчётам, не доказательство прямого перемещения. Удаление и повторное добавление внутри одного спринта не считаются.

Дополнительное чтение задач. Источник оценок — паспорт доски в дашборде метрик. Возраст — календарные часы 24×7 по истории Jira, не Timepiece. При неполной истории значения неизвестны.

Профиль команды

Файл содержит JQL, колонки и расписания, настройки визуала, правила refinement и паспорта метрик по ID досок. Результаты запросов, снимки, задачи и данные сессии в файл не входят. Текст JQL может содержать внутренние названия — файл предназначен для коллег вашей компании.

Импорт заменяет настройки визуала и refinement, обновляет паспорта указанных досок. Существующие результаты и снимки сохраняются. Новые JQL добавляются на паузе, точные дубликаты пропускаются. Паспорта привязаны к ID досок этой Jira.
