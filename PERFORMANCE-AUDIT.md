# Аудит производительности — 2026-11-28

Версия: 0.32.0 → 0.32.1. Проверены обработка доски (active-board/content), аналитика Control и подготовка роадмэпа. Корпоративная Jira не использовалась: все данные синтетические.

## Исправленные узкие места

- `src/control-core.js`: одна история задачи разбиралась и сортировалась повторно для строк, когорт и итогов спринта. Теперь результат переиспользуется в пределах одного вызова analyze. После изменения снимка следующий вызов считает заново; постоянного кэша нет.
- Подсчёт возвратов создавал срез истории для каждого перехода и искал в нём предыдущий статус (квадратичный рост). Теперь используется множество предыдущих статусов и один проход. Текущий переход добавляется после проверки, чтобы не изменить смысл самопереходов.
- Каждый процентиль просматривал всю когорту и создавал промежуточный массив. Теперь когорты сортируются один раз, число длительностей ≤ возраста определяется бинарным поиском. Повторы, минимальный размер когорты и неизвестные значения сохранены.
- `src/roadmap-core.js`: при добавлении каждой задачи и зависимости сериализовался весь растущий JSON. Теперь сериализуется только новая строка, учитываются разделители и изменение длины счётчика пропущенных задач. Порядок, ограничения 145000/185000 и итоговый объект сохранены.

## Продолжение аудита: 0.32.1 → 0.32.2

Закрыты три кандидата из раздела «Остальные наблюдения»: обработка DOM, обновление карточек, обход зависимостей. Работа выполнена в `ProjectATL/jira-board-plus`; исходная версия для сравнения — тег `v0.32.1`.

### Изменения

- **Панель задачи:** observer проверяет только изменения внутри панели, её появление/удаление и изменения предков. Внутренние изменения UI расширения игнорируются. Секундный таймер сравнивает URL, не сканирует DOM на неизменившейся странице. Сохранены pushState-навигация, скрытие/замена контейнера, редактирование текстового узла ключа, удаление хоста расширения и возобновление скрытой вкладки.
- **Доска:** посторонние DOM-изменения не запускают обновление. Замена пула, карточек, удаление меток, смена data-issue-key и навигация продолжают обрабатываться. Один запланированный callback обслуживает пакет изменений через 80/120 мс; непрерывные события больше не перезапускают отсчёт.
- **Карточки:** видимый список сканируется один раз в синхронной части refresh и переиспользуется для draw, очереди запросов и проверки лимита. После асинхронной загрузки список берётся заново. Атрибуты, CSS-переменные и текст ошибок записываются только при изменении.
- **Риски:** повторная отрисовка использует результат анализа тех же данных, правил и завершённых статусов. Данные/правила/настройки инвалидируют кэш; временной ключ меняется каждые 15 секунд. При изменении только времени пороги обновляются по штатному 15-секундному таймеру доски, а не на каждое DOM-событие. Очистка/смена доски сбрасывает кэш.
- **Зависимости:** рекурсивный DFS заменён явным стеком и индексами активного пути. Исчезли копирование пути на каждом ребре и ограничение глубиной стека JavaScript. Порядок обнаружения циклов и итоговая модель совпадают с прежними на сопоставимых графах. При замыкании цикла его узлы по-прежнему перечисляются; линейная сложность для произвольных плотных графов не заявляется.
