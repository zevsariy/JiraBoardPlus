# 0.16.1 — Выбор поля версии

1. Обновите расширение, откройте роадмэп, выберите Component/s. Между компонентами и релизом есть «Поле релиза»: Fix Version / Affects Version. По умолчанию Fix Version.
2. Выберите релиз с корневой задачей, у которой эта версия указана только в Affects Version. В режиме Fix она отсутствует, после переключения на Affects появляется. Смена режима должна автоматически обновить уже выбранный релиз.
3. Потомки без соответствующей версии остаются в дереве. Откройте подробности: видны оба списка версий, предупреждение соответствует выбранному полю.
4. Быстро переключите поля во время загрузки. Итоговые данные и подпись над диаграммой должны соответствовать последнему выбору.
5. Перезагрузите страницу: поле версии и компоненты восстановлены для проекта. Выберите релиз для загрузки; запросов задач до его выбора нет.
6. Экспортируйте JSON/Markdown или откройте снимок ИИ: versionField равен fixVersion либо affectedVersion, у задач есть fixVersions и affectedVersions. Контроль сроков, Team, зависимости и лимит 2000 сохранены.
