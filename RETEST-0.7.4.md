# Повторная проверка M01 · актуально для 0.7.5

1. Обновите распакованное расширение в chrome://extensions и перезагрузите страницы отчётов. Нажмите значок расширения, откройте «Подключение к Jira и проект». Видны поля базового URL и ключа/ID проекта; URL по умолчанию https://jira.example.com. Введите ключ своего проекта и нажмите «Сохранить подключение». Ожидается сообщение «Сохранено»; после повторного открытия меню значения сохранены.
2. Откройте «Дашборд метрик». Вверху отображаются URL и проект, ниже — поля «Доска» и «Спринт». Кнопки «Загрузить спринты» и поля context path нет. Доски загружаются автоматически, появляется число досок. Спринт недоступен до выбора доски.
3. Нажмите поле «Доска». Ожидается выпадающий список названий с типом и ID. Введите часть названия из середины, меняя регистр букв. В списке остаются подходящие варианты. Кликните вариант: название появляется в том же поле, список закрывается, начинается загрузка спринтов.
4. Нажмите поле «Спринт», введите часть названия. Видны совпадающие активные и завершённые спринты с пометкой состояния и ID. Выберите кликом либо стрелками и Enter. Панель выбранного Sprint Report появляется сразу и автоматически загружает расчёты. Кнопки «Открыть» нет. После загрузки доступны метрики и экспорт; кнопка «Обновить данные» повторяет загрузку.
5. Выберите другую доску, затем быстро ещё одну. Ожидается очистка выбранного спринта и прежней панели. После загрузки показываются только спринты последней выбранной доски, запоздавший ответ не заменяет список.
6. Введите заведомо отсутствующую часть названия. В выпадающем списке видно «Ничего не найдено», произвольный текст нельзя принять как ID. Escape закрывает список. Для Kanban показывается пояснение, что для спринтовых метрик нужна Scrum-доска. При пустом проекте — просьба задать его в настройках, без запросов к Jira.
7. При реальной ошибке доступа/сети/HTTP у списка виден текст ошибки и крестик справа. Нажмите крестик: сообщение исчезает. Кнопка «Повторить загрузку списка» позволяет повторить запрос. При ошибке загрузки данных внутри панели метрик также есть крестик.
8. На странице JQL раскройте настройки. Поля context path больше нет; показан сохранённый адрес Jira и подсказка о настройках в меню расширения. Сохранённые запросы и результаты остаются после изменения только проекта.
9. В уже открытом дашборде измените проект через меню расширения и сохраните. Список досок обновляется сам; предыдущие доска, спринт и панель сбрасываются. Не меняйте URL только ради проверки: смена установки Jira после подтверждения очищает прежние результаты JQL и базу сравнения.

Если Jira фактически установлена в подкаталоге, полный URL должен содержать этот путь, например https://jira.example.com/jira. Не добавляйте /jira для сервера, установленного в корне.
