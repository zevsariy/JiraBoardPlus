# Ручная проверка 0.11.0

## K01 — Kanban без спринтов
Откройте «Метрики команды», найдите Kanban-доску проекта и выберите её. Ожидается: выбор спринта скрыт, обзор загружается автоматически; сверху надпись KANBAN.

## K02 — текущая работа и переход к задачам
Нажмите «Незавершённые», «WIP» или «Заблокированы». Страница прокручивается к списку соответствующих задач; ключ открывает Jira в новой вкладке. WIP учитывает общие рабочие статусы. Укажите лимит ниже текущего WIP: появляется «ПРЕВЫШЕН».

## K03 — возраст и зависимости
Измените порог возраста на 1/30 дней. Счётчик стареющих задач меняется без нового запроса. Возраст считается от последнего перехода, в календарных днях. Задача в настроенном blocked-статусе с несколькими блокерами попадает в «Блокеры уже завершены» только если статусы всех блокеров входят в общие правила разблокировки. Неизвестный статус не считается завершённым.

## K04 — период и качество
Выберите 7/90 дней или даты вручную и нажмите «Применить период». Обновляется недельная таблица. Текущий WIP не становится историческим. Проверьте качество: усечённая история уменьшает выборку времени/завершений; такие задачи доступны по отдельной кнопке. Неполные недели подписаны.

## K05 — типы и видимость
Выберите Bug: все показатели обзора и списки содержат только Bug. Включите подзадачи. Раскройте «Видимость разделов», отключите поток; раздел исчезает. Повторно выберите ту же доску: настройки видимости, порога и лимита сохраняются.

## S01 — Scrum и переопределение
Выберите Scrum-доску: доступны спринты и общий обзор. Переключите режим на Kanban: поле спринта скрывается, общий обзор продолжает работать. Верните Scrum и выберите спринт: данные Sprint Report загружаются автоматически.

## S02 — динамика
Нажмите «Загрузить динамику», выбрав 3/5/10. Видны только завершённые спринты, их исходный план, добавленные/исключённые задачи, выполнение. Нажатие числа открывает соответствующие задачи. «Повторно незавершённые» показывает задачи, незавершённые в двух и более выбранных спринтах. Кнопка отмены останавливает загрузку.

## S03 — оценки и активный спринт
Проверьте SP, Original Time Estimate и доску без оценок. Единицы не смешиваются; в динамике для отсутствующих оценок написано «Без оценок». В активном Sprint Report раскройте «Риски активного спринта»: показываются задачи без исполнителя либо с текущим статусом ≥7 дней. Отключите «Риски активного спринта» в основных настройках — блок исчезает.

## A01 — экспорт и ИИ
Выберите тип, выгрузите JSON: mode=kanban/scrum, фильтры и задачи совпадают с экраном, личных заметок/описаний/полного changelog нет. При включённой кнопке ИИ для Sprint Report/метрик откройте «Анализ обзора через ИИ»: сначала снимок, отправка только по отдельной кнопке. В снимке есть режим и ограничения расчётов.

## E01 — ошибки и навигация
При ошибке загрузки виден текст с крестиком, доступно повторное обновление. Быстро переключите доски: поздний ответ старой доски не заменяет выбранную. Попробуйте будущий/обратный период — понятная ошибка. При отсутствии оценок общие метрики продолжают работать.
