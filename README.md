# Jira Board Plus

Расширение Google Chrome для Jira Server / Data Center: дополнительная информация на карточках, JQL-отчёты, метрики Scrum и Kanban и роадмэп релиза в одном интерфейсе.

Board Plus работает поверх вашей Jira, используя текущую сессию браузера и права пользователя. Основные разделы открываются из меню **Board Plus** в шапке Jira или отдельными вкладками расширения. Устанавливать серверную часть Board Plus не требуется.

## Возможности

| Раздел | Что можно делать |
| --- | --- |
| **Доски и бэклог** | Редактировать Shared Team в Details с поиском по названию; видеть отсутствие исполнителя, блокировки, наличие билда и задачи, добавленные после старта спринта. |
| **Контекст задачи** | Смотреть выбранные поля родителей через настраиваемые связи, время в статусах из Jira или Timepiece, создавать личные локальные заметки. |
| **JQL-отчёты** | Добавлять свои запросы, выбирать и упорядочивать колонки, запускать по расписанию, сравнивать результаты и получать уведомления об изменениях. |
| **Метрики** | Анализировать Scrum и Kanban: WIP, возраст задач, lead/cycle time, выполнение плана и изменения состава спринта. Использовать графики, фильтры по типам и исполнителям, P50/P70/P80/P85. |
| **Sprint Report** | Дополнять родной отчёт Jira фильтрами и метриками, сохранять локальные снимки и выгружать данные в JSON, Markdown или CSV. |
| **Роадмэп** | Строить Гант и граф зависимостей по Fix Version или Affects Version, настраивать иерархию, отбор корневых задач, поля и команды; контролировать Due Date и отсечку разработки. Сохранять планы, снимки, локальные сценарии и резервные копии. |
| **Инструменты** | Проверять готовность к refinement по выбранным правилам, анализировать переносы между спринтами, импортировать и экспортировать профиль команды. |
| **ИИ — по желанию** | Отправлять выбранный снимок данных на настроенный пользователем OpenAI-совместимый сервер, менять системный промпт и читать форматированный ответ. |

Дополнительный визуал включается по функциям. Оценки поддерживают Story Points и Original Time Estimate; общие правила статусов и поле Team задаются в настройках. Предустановленных JQL-запросов и адреса Jira нет.

## Установка

1. Скачайте архив `jira-board-plus-<версия>.zip` из [последнего релиза](https://github.com/zevsariy/JiraBoardPlus/releases/latest) и распакуйте его в постоянную папку.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку, содержащую `manifest.json`.
4. Откройте расширение и пройдите мастер первоначальной настройки.
5. Перезагрузите открытые вкладки Jira.

Для обновления замените файлы в той же папке, нажмите **Обновить** на карточке расширения в `chrome://extensions` и перезагрузите Jira. Не удаляйте расширение перед обновлением: удаление может привести к потере его локальных данных. Перед переустановкой экспортируйте нужные настройки и резервные копии.

## Первое подключение

- Укажите полный HTTPS-адрес Jira и ключ проекта. Если Jira установлена в подкаталоге, включите его в адрес, например `https://jira.example.com/jira`.
- Разрешите расширению доступ к выбранному серверу и войдите в Jira в этом же профиле Chrome.
- Выберите поле **Team** из справочника Jira, если используете команды. Не нужно искать ID вручную: доступен поиск по названию.
- Задайте общие статусы работы, завершения и блокировки; включите необходимые дополнения.
- Откройте **Board Plus** в верхнем меню Jira и выберите нужный раздел. Пояснения доступны во встроенной **Справке**.

## Требования и ограничения

- Расширение предназначено для Jira Server / Data Center. Поддержка Jira Cloud не заявлена.
- Доступ к задачам и возможность редактировать Team определяются правами пользователя Jira. Для редактора Shared Team требуется соответствующее поле Plans / Advanced Roadmaps на экране редактирования задачи.
- Timepiece нужен только для выбора этого источника времени; доступен и источник Jira. Форматы API сторонних плагинов зависят от их версии.
- Роадмэп загружает до 2000 задач по умолчанию, с настройкой до 5000. Большие выборки нужно сужать фильтрами. Общий обзор метрик ограничен 3000 задачами за загрузку.
- Локальные сценарии роадмэпа не изменяют Jira. Редактирование сроков задач выполняется в самой Jira.
- Расписание JQL выполняется средствами Chrome: закрытый браузер не заменяет постоянно работающий сервер планировщика.

## Данные и конфиденциальность

Настройки, снимки, результаты отчётов и личные заметки хранятся локально в профиле браузера. Личные заметки не публикуются как комментарии Jira и не синхронизируются между устройствами.

Для работы расширение обращается к настроенной Jira. Необязательный анализ ИИ отправляет данные на выбранный вами сервер только после действия в окне анализа; перед отправкой доступен просмотр снимка. Условия хранения этих данных определяет выбранный сервер ИИ.

Подробнее: [политика конфиденциальности](PRIVACY.md) — обращения к Jira и ИИ, локальное хранение, разрешения, экспорт и удаление данных.

Исходники используют HTML, CSS и JavaScript, расширение — Manifest V3.

```sh
git clone https://github.com/zevsariy/JiraBoardPlus.git
cd JiraBoardPlus
npm test
python scripts/package.py
```

Для тестов нужен Node.js, для упаковки — Python 3 и Git. Архив создаётся в `dist/`. Браузерные проверки используют Playwright и подставные ответы Jira; дополнительные сведения — в [DEVELOPMENT.md](DEVELOPMENT.md). Локальные файлы повторных проверок `RETEST-*.md` не публикуются в репозитории и релизах.
