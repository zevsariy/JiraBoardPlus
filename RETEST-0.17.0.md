# Проверка 0.17.0

1. Выберите компоненты и релиз. Над Гантом доступна кнопка «АНАЛИЗ ИИ». Настройте модель и разрешите роадмэп; откройте окно, проверьте снимок и отправьте его. Без настройки модели отображается ссылка на настройки, отправка недоступна.
2. Задайте отсечку раньше окончания задач. На Ганте появляется линия отсечки, задачи за датой красные, под Гантом — список проблем. Окончание ровно в день отсечки допустимо. Очистите дату — проверка отключается. После повторного выбора того же релиза дата восстанавливается; для другого релиза задаётся отдельно. Jira не изменяется.
3. Выгрузите JSON и Markdown: start/end/due/rootDue, даты спринтов, релиза и отсечки записаны UTC ISO 8601 с годом, месяцем, днём и временем. Неизвестные даты — null.
4. Сравните соседние корневые задачи с детьми и без: ссылки должны начинаться на одинаковом отступе. Проверьте раскрытие/сворачивание.
5. Зависимости фиолетовые, конфликты красные; отключение стрелок работает. Проверьте обе темы.
6. Сначала отображается Гант, ниже сводка проблем и зависимости.
