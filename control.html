Поля, статусы и период спринта

История состава спринта требует ID и начала спринта. Чтобы увидеть удалённые задачи, JQL должен включать их, а не только текущий Sprint. Оценки показаны в исходных единицах выбранного поля. Для локализованных связей задайте ID типа связи.

Очередь внимания

Цвет сопровождается объяснением. Пороговые сигналы — повод проверить задачу, а не оценка сотрудника.

Поток и зависимости

Кандидаты на узкое место определяются по текущей очереди и возрасту. Рост очереди вычисляется только между сопоставимыми снимками. Возраст сравнивается с завершёнными посещениями того же статуса задачами того же типа (минимум 5 наблюдений), календарное время 24×7.

Журнал состава и оценок

Наблюдаемые события выбранного периода. При заданном ID спринта изменения оценок включаются только при подтверждённом участии задачи в нём в момент изменения. Без ID показываются изменения оценок за весь период. Причины переносов нельзя доказать по одному журналу: ниже показаны признаки для обсуждения.

Признаки возможных переносов

Вероятностный прогноз

Модель использует завершения из выбранного JQL по полным календарным дням UTC, включая дни без завершений. Выберите однородную работу одной команды и включите завершённые задачи в JQL.

Подготовка встречи

Форматирование для Confluence копируется как HTML и обычный текст; итог зависит от редактора Confluence. Публикация выполняется вами.

Отметки разбора на refinement

Отметки хранятся локально отдельно от задач Jira.

Правила сигналов и подсветки

Правила применяются к незавершённым задачам в снимке и к доступным данным карточек доски. Если поле или полная история отсутствует, правило по нему не срабатывает. Для доски используются общие настройки завершённых статусов.

Помощник по данным

Используется настроенная модель и разрешение «Анализ доски». Перед каждым запросом открывается просмотр данных и адреса сервера. Ответы не изменяют Jira; JQL выполняется только вручную после проверки.

Нагрузка и совместимость

Глубокая диагностика Jira: сеть, сервер и браузер

Бюджет общий для запросов расширения к настроенной Jira во всех вкладках. Штатные запросы Jira и запросы ИИ не учитываются. Счётчики сохраняются в течение сессии браузера; 429/5xx приостанавливают новые запросы. Долгая очередь может привести к тайм-ауту загрузки.
