# Проверка 0.7.10

Обновите распакованное расширение в chrome://extensions и перезагрузите вкладку Jira. Откройте меню расширения → настройки. После изменений нажимайте «Сохранить настройки».

1. **Бэклог:** включите daily и «Анализ карточек в бэклоге». В режиме планирования Scrum/канбан на видимых карточках должны появиться те же включённые метки, что на доске. Отключите анализ бэклога — метки исчезнут, Team останется. Анализ активной доски продолжает работать. Нажатия на разные карточки не должны повторно загружать весь набор данных. Обрабатываются первые 300 видимых карточек; при превышении есть сообщение в сводке.
2. **Блокировки:** в разделе daily включите блокировки. Укажите статус своей задачи, например Waiting, и статусы снятия блокировки, например Released, Obsolete. Задача в WAITING с is blocked by получает «ЗАБЛОКИРОВАНА», пока хотя бы одна связанная задача не завершена по этому списку. Когда все имеют указанные статусы — «РАЗБЛОКИРОВАНА». Недоступная связь не должна давать зелёную метку. Категория Done сама по себе не снимает блокировку. Названия сравниваются без учёта регистра.
3. **Team:** на активной доске откройте Details → Team. Напечатайте Dev посимвольно: текст остаётся в поле, окно редактирования Jira не открывается. Проверьте выбор мышью, стрелками и Enter, закрытие Escape. После выхода из поля обычные горячие клавиши Jira работают. Повторите в бэклоге.
4. **Есть билд:** включите метку в настройках. По умолчанию статус Resolved, поле Fixed In. У задачи с этим статусом и непустым полем появляется «Есть билд». При пустом поле или другом статусе метки нет. Проверьте другой настроенный статус и смешанный регистр. Изменения данных видны после «Обновить» в сводке или фонового обновления (до двух минут). В бэклоге дополнительно нужен его выключатель анализа.
5. **Поле билда:** при неизвестном имени либо неоднозначном имени появляется «Билд: ?»; наведите курсор для причины. Для одинаковых имён укажите точный ID customfield_NNNNN. Fixed In не заменяется полем Fix Version.
6. **Выключатели:** отключение метки билда скрывает только её. Общий выключатель визуала убирает все дополнения. После закрытия/повторного открытия настроек значения сохраняются.

Автоматические проверки используют локальные подставные ответы. Реальная вёрстка и доступность полей корпоративной Jira требуют этой ручной проверки; запросы к ней при разработке не выполнялись.
