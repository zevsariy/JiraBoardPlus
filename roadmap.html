Область роадмэпа

Достаточно совпадения с любой меткой. Используйте точное написание меток Jira.

Без ORDER BY. Условие пересекается с проектом, релизом и типами корневого уровня.

Выберите один или несколько компонентов проекта. Без выбора загрузка задач не выполняется.

Корневые задачи выбранных типов должны соответствовать области, проекту и релизу по выбранному полю версий. Вниз загружается вся настроенная иерархия, включая задачи с другими или пустыми Component/s, задачи других релизов и проектов. Изменения выполняются в Jira по ссылке на задачу.

Настройки роадмэпа · иерархия и поля Jira

Настройки сохраняются для текущего сервера и проекта. Сверху — тип корневой задачи; каждый следующий уровень задаёт типы потомков и поле, в котором у них хранится ссылка на родителя. Например: Component → Epic через Parent Link → Task через Epic Link.

Для контроля фич используется стандартное Due Date корневой задачи. Статусы завершения и разблокировки — общие настройки расширения. Поле Team здесь задаётся отдельно для роадмэпа.

Проверка назначения спринта

Проверяются незавершённые задачи выбранных типов. Любой назначенный спринт, включая закрытый, считается назначением. Для Kanban оставьте правило выключенным.

Поля рядом с задачами · до 30

Добавляйте поля кликом или Enter; меняйте порядок стрелками. Полные значения доступны в подробностях и попадут в выгрузку и снимок ИИ.

Исключение веток

По одной маске на строку, без учёта регистра. Текст ищется внутри названия или ключа, * означает любые символы. Совпавшая задача и все потомки исключаются. Внешняя зависимость на неё может остаться как блокер.
